Конфиденциальность

Какие данные использует приложение

Приложение работает с отдельной папкой резервных копий Google Диска владельца бота. Копия базы может содержать рецепты, в том числе личные, Telegram ID, сохранённые рецепты, избранное и другие связанные записи базы бота.

Разрешение Google drive.file даёт доступ только к файлам, созданным или явно используемым с этим приложением. При подключении проверяется адрес Google-аккаунта владельца. Почта Gmail, Google Фото и остальные файлы Диска для работы приложения не нужны и не запрашиваются.

Для чего нужны данные и где они хранятся

Единственное назначение — защита данных бота и возможность восстановления после сбоя. Резервные копии передаются из Amvera в Google Диск владельца; для проверки копия скачивается во временное хранилище приложения. Её размер, контрольная сумма и целостность базы проверяются до подтверждения успеха.

Папка и файлы проверяются на отсутствие общего доступа. Приложение не публикует копии, не использует их для рекламы и не передаёт для обучения ИИ. Оно использует Google API в рамках Google API Services User Data Policy.

Хранение и управление доступом

После подключения автоматической схемы планируется хранить 14 последних проверенных поколений. Более старые копии приложение перемещает в корзину Google Диска после успешной проверки новой. Google обычно удаляет содержимое корзины через 30 дней; приложение само корзину не очищает.

Владелец может скачать или удалить файлы на Google Диске, а также отозвать доступ приложения в настройках связей своего Google-аккаунта. Отзыв доступа останавливает дальнейшее копирование, но сам по себе не удаляет уже сохранённые файлы. Вопросы о данных можно направить владельцу: kharlamov1991@gmail.com.
